# Spotify Popularity Analysis
This project analyzes Spotify datasets in order to investigate relationships between audio features and song popularity.

The analysis includes:
- Data cleaning
- Exploratoty data analysis
- Correlation analysis
- Regression modeling
- Hypothesis testing

Technologies used:
  - Python
  - Pandas
  - Seaborn
  - Mathplotlib
  - Scikit-learn
  - SciPy
